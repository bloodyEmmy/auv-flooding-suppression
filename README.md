Протокол реализует последовательный доступ к сети с подавлением
широковещательного шторма. В отличие от классического flooding,
рассылка OFS/routing-обновлений выполняется только при критических
событиях: обнаружении нового узла, изменении критического
маршрута или периодическом обновлении. В фазе Routing Maintenance
broadcast разрешён только при одновременном выполнении условий Hij'
≠ Hij и CRj = 0, где CRj = 0 означает, что целевой узел является
критическим узлом маршрутизации.
Цель симуляции — показать, что предложенный протокол снижает Total
Overhead более чем на 30% по сравнению с flooding при сохранении PDR
выше 95% в статичной топологии.
